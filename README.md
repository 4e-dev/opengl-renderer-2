# OpenGL Renderer 2

## Building from source

Dependencies:
* gcc
* meson

Building with Meson:
meson setup build (only needs to be done once)
meson compile -C build
    * this generates the test binary as well

Changing the Meson build file:
meson setup build --reconfigure

## LSP
cp build/compile_commands.json ../ (this gets generated by meson)
*OR* `bear -- make` to generate a compile_commands.json
